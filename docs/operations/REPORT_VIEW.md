# 网页诊断报告摘要

任务详情可查看四种固定报告：accuracy、compiler、simulation、operator。只读接口为`GET /api/jobs/JOB/diagnostic-report?kind=simulation`等；沿原jobs:read、owner/project和预算绑定授权，没有提交、采集、实验或原路径覆盖参数。控制器/api/me声明report_view_capabilities中的archive-report-view-v1。旧中央缺能力时界面明确提示升级，保留原产物下载入口。

报告展示前，中央检查确切受控Node/attempt、明确终态、执行与所分配资源清退确认、匹配的归档回执；完整artifact-hashes.json与回执摘要须一致。随后只读取固定的小报告及编译stderr，核对其完整长度/SHA与确认清单一致。符号/硬链接、变化、未知状态、清退不全、缺件和不一致被拒绝；回收站/清理中的归档沿原生命周期门禁。不会因打开网页而重跑或释放任务。

报告上限分别为精度32KiB、编译16KiB、仿真128KiB、历史性能64KiB；错误日志8KiB、呈现前4096字符，确认清单最多2MiB/2000项，响应192KiB。JSON拒绝重复键、NaN/Inf、超过32字符的整数和过深/超节点结构。中央最多同时处理两个此类读取，繁忙返回503供原查看操作重试，不创建后台分析任务，不读取完整trace、tensor、IR或CSV，也不在HTTP线程中重算大文件。

网页摘要是**工作负载报告**：只核报告字节与Node确认归档的对应关系，包含有限结构和数值一致性检查；完整源文件及数值结果未在此重算。它不提供独立精度、参考正确性、采集完整性或优化收益认证。个人CLI/MCP的accuracy-case、compiler-case、simulation-case等仍提供原有的完整来源核验路径。报告来源、原任务状态和这种校验范围在界面分别展示。

精度视图显示给定参考ID、政策、元素/差异数、有限样本及误差指标；“与给定参考一致”不等于通用精度验收。编译视图显示工具版本/摘要、输入IR摘要、返回码/超时和有界错误日志；解析接受不代表完整lowering或正确性。仿真视图可切换最多4核，显示各pipe记录区间并集/该核记录跨度；这些区间可重叠，不能相加为总利用率或删改可节省时间，原signal/异常采集状态保持独立。历史性能视图显示观测均值比例及限制条件，优化收益保持未知。

页面按本人授权的产物索引提供按钮，点击才读取报告。未知/活动任务不显示可用结论；切换任务、关闭抽屉或重新选择报告会取消旧读取并丢弃过时响应。请求有有限观察时限；失败保留原任务和重试查看入口。所有报告字符串作为文本渲染，源码路径只作标签；图表使用本地DOM和progress，不加载外部脚本、URL或执行报告内容。

实际浏览器和安装证据以PROGRESS.md为准。网页图表只是记录区间覆盖率摘要，不是完整指令时间线；完整流水文件继续通过原授权归档下载。真实设备、多机和正式领域诊断验收仍按DEPLOYMENT.md推进。
